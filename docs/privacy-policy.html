Screen Time Tracker — Terakhir diperbarui: 10 November 2026

Ringkasan

Screen Time Tracker ("aplikasi") adalah pelacak kebiasaan pemakaian HP (screen time) dengan pendamping 3D. Aplikasi ini dirancang agar seluruh data pemakaian tetap berada di perangkat kamu, bukan di server kami.

Data yang dikumpulkan

  • Statistik pemakaian aplikasi — aplikasi mana yang dibuka, berapa lama, dan berapa kali (melalui izin "Akses pemakaian" Android).
  • Daftar aplikasi terpasang — hanya nama paket dan label aplikasi, untuk menampilkan peringkat dan label di rekap.
  • Metadata gulir (opsional) — hanya jumlah gulir, TIDAK membaca isi layar. Fitur ini mati secara bawaan dan hanya aktif bila kamu mengaktifkan "Aksesibilitas (hitung scroll)" secara manual.

Data yang TIDAK dikumpulkan

  • Tanpa akun, tanpa nama, email, nomor telepon, atau lokasi.
  • Tanpa membaca pesan, foto, kontak, atau isi layar aplikasi lain.
  • Tanpa iklan dan tanpa SDK analitik pihak ketiga.

Penyimpanan dan berbagi

Semua data tersimpan lokal di perangkat (SharedPreferences dan database SQLite). Tidak ada data yang dikirim ke server mana pun; satu-satunya lalu lintas jaringan adalah memuat model 3D dari localhost di perangkat itu sendiri.

Data tidak dibagikan kepada pihak ketiga mana pun.

Kontrol kamu

  • Kamu dapat mencabut izin kapan saja lewat Pengaturan Android.
  • Kamu dapat menghapus seluruh data aplikasi lewat menu Profil → Privasi & backup → hapus data.
